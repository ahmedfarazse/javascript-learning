# JavaScript Promises & Async/Await

This folder contains JavaScript examples and practice exercises for async/await.

Promises and async/await are used to handle asynchronous operations in JavaScript.

---

## Purpose

- Understand JavaScript Promises
- Learn Promise states
- Practice resolve() and reject()
- Handle successful and failed Promises
- Learn then(), catch(), and finally()
- Practice Promise chaining
- Understand Promise utility methods
- Learn async and await
- Handle errors using try/catch/finally
- Understand sequential and concurrent asynchronous operations
