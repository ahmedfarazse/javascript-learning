# CommonJS vs ESM

This folder contains JavaScript CommonJS and ECMAScript Module (ESM) examples and practice exercises.

Understanding both module systems is essential for working with modern JavaScript and Node.js applications.

---

## Purpose

- Understand CommonJS
- Understand ECMAScript Modules (ESM)
- Learn require() and module.exports
- Learn import and export
- Compare CommonJS and ESM
- Prepare for modern Node.js development
