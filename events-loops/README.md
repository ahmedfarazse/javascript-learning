# JavaScript Event Loop

This folder contains notes and examples for understanding the JavaScript Event Loop.

The Event Loop explains how JavaScript handles synchronous and asynchronous code.

---

## Purpose

- Understand the Call Stack
- Understand synchronous and asynchronous execution
- Learn how the Event Loop works
- Understand the Microtask Queue
- Understand the Task / Callback Queue
- Learn how Promises are scheduled
- Understand how setTimeout() is scheduled
- Practice predicting JavaScript execution order
