# JavaScript Promises

This folder contains JavaScript Promise examples and practice exercises.

Promises are used to handle asynchronous operations and make asynchronous code easier to manage.

---

## Purpose

- Understand JavaScript Promises
- Learn Promise states
- Practice resolve() and reject()
- Handle successful and failed Promises
- Learn then(), catch(), and finally()
- Practice Promise chaining
- Understand Promise utility methods
- Prepare for async/await and asynchronous JavaScript
